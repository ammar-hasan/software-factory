# Claims ledger

Every factual assertion spoken in this film traces to a file in the subject
repository at `/home/user/software-factory`, or to the recorded output of a
command actually run against it on 2026-09-01. Nothing here is a summary of a
summary; each source was read directly.

Two standing rules for this script, tighter than the tool requires:

1. **No result is claimed that the project has not produced.** The central
   experiment has no trials. The film says so, in the tool's own words.
2. **No comparison to any other product, tool, vendor, or model is made,**
   including by implication. The one comparative sentence in the script is a
   verbatim quotation of the project's own hypothesis about model tiers and
   harness quality, and is delivered and captioned as a quotation under test.

## How the on-screen plates were transcribed

Every plate is real output. Three of them are shown shorter than the terminal printed them,
and each elision is recorded here so the film cannot be read as showing more than it did:

| Plate | Exactly what was done |
| --- | --- |
| `sf work "…" --dry-run` (TRIAGE) | complete and unaltered, all four output lines, wrapped at the same point the shell wrapped the command |
| `sf providers` (HANDOFF) | complete, captured at `COLUMNS=150` so the endpoint column is not wrapped by terminal width; characters unchanged |
| `sf audit --egress` (HANDOFF) | complete and unaltered |
| `sf experiment status` (VERIFY) | **elided.** The tool prints the three-line hypothesis statement, a blank line, then the verdict. The plate shows the command and the verdict line `insufficient_data — no trials recorded`, verbatim. The elided statement is the same claim the film has already quoted in full in the DESIGN scene. |
| `docs/trials.md` gate rows (REVIEW) | **whitespace reflowed, wording unchanged.** The report indents each row four spaces and pads the gate column wider; the plate narrows that padding to fit 1280 px. The gate names, verdicts and reasons are character-for-character the report's. |
| the blocker sentence (REVIEW) | **elided and re-cased.** The report reads: *"The test failed before its body ran, so it proves the code did not exist, not that the behaviour was wrong. Assert on behaviour that the parent commit gets wrong."* The plate carries the first sentence, lower-cased as a continuation line, and drops the second. |

The dashboard card in the VERIFY scene is a crop of `docs/images/dashboard-overview.png` at
its native resolution. Nothing in it is recoloured, retyped, rescaled or rearranged.

## Deliberately not claimed

- Any pass rate, cost, speed, or quality result. None exists: the experiment
  has recorded no trials.
- Any comparison with a named product, vendor, model, or service.
- That the three end-to-end trials say anything about model output quality.
  They do not — the model is scripted in all three, and the report says so.
